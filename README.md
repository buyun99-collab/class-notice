# 교실 공지 알림 시스템 설치 안내

교무실이나 휴대폰에서 공지를 쓰면, 각 교실 전자칠판(안드로이드) 화면 위에 큰 팝업으로 뜨는 시스템입니다. 수업 중에 PPT나 유튜브를 띄워 놓은 상태에서도 그 위에 덮어서 표시됩니다.

## 1. 구성

| 구성 | 위치 | 하는 일 |
|---|---|---|
| 칠판 앱 | `android` 폴더 | 칠판마다 설치. 켜져 있는 동안 계속 대기하다가 공지가 오면 팝업 |
| 관리자 페이지 | `admin/index.html` | PC, 휴대폰 브라우저에서 공지 작성과 전송 |
| 중계 서버 | ntfy.sh (무료 공개 서비스) | 관리자 페이지에서 보낸 공지를 칠판들에 전달 |

학교에 서버를 따로 둘 필요가 없습니다. 공지는 **채널 이름**으로 구분되며, 채널 이름을 아는 사람만 공지를 보낼 수 있습니다. 그래서 채널 이름은 비밀번호처럼 길고 추측하기 어렵게 정하고, 선생님들께만 알려 주세요.

## 2. 먼저 확인할 것

1. 칠판 한 대에서 브라우저를 열고 `https://ntfy.sh` 에 접속되는지 확인합니다. 화면이 뜨면 학교망에서 사용할 수 있습니다.
2. 칠판에 외부 앱(APK)을 설치해도 되는지 정보부장님이나 납품 업체에 확인합니다. 일부 칠판은 업체 잠금이 걸려 있습니다.

## 3. 칠판 앱(APK) 만들기

### 방법 A: GitHub에서 자동으로 만들기 (프로그램 설치 필요 없음)

1. https://github.com 에 가입합니다.
2. 오른쪽 위 ‘+’ 버튼에서 ‘New repository’를 누르고, 이름을 `class-notice` 처럼 정한 뒤 **Public**으로 만듭니다. 코드 안에는 채널 이름 같은 비밀 정보가 없으므로 공개해도 괜찮습니다.
3. 만든 저장소 화면에서 ‘uploading an existing file’을 누르고, 이 압축을 푼 폴더 안의 내용(`.github`, `admin`, `android`, `index.html`, `README.md`)을 모두 끌어다 놓은 뒤 ‘Commit changes’를 누릅니다.
   - `.github` 폴더는 숨김 폴더라서 맥에서는 보이지 않을 수 있습니다. Finder에서 Command + Shift + . 을 누르면 보입니다.
4. 저장소 위쪽 ‘Actions’ 탭으로 갑니다. ‘칠판 앱 APK 만들기’ 작업이 자동으로 돌아갑니다. 5분쯤 지나 초록색 체크가 뜨면 그 작업을 눌러 아래쪽 ‘Artifacts’의 `class-notice-apk`를 내려받습니다.
5. 내려받은 zip 안의 `app-debug.apk`가 칠판에 설치할 파일입니다.

### 방법 B: Android Studio로 만들기

Android Studio에서 `android` 폴더를 열고, 메뉴의 Build, Build App Bundle(s) / APK(s), Build APK(s) 순서로 누르면 됩니다.

## 4. 관리자 페이지를 휴대폰에서도 열 수 있게 하기

방법 A로 저장소를 만들었다면 그대로 이어서 합니다.

1. 저장소의 ‘Settings’, 왼쪽 ‘Pages’로 갑니다.
2. ‘Branch’를 `main`, 폴더를 `/ (root)`로 고르고 ‘Save’를 누릅니다.
3. 1~2분 뒤 `https://내아이디.github.io/class-notice/` 주소가 생깁니다. 이 주소를 PC와 휴대폰에서 열면 관리자 페이지입니다.
4. 휴대폰에서는 브라우저 메뉴의 ‘홈 화면에 추가’를 누르면 앱처럼 쓸 수 있습니다.

PC에서만 쓸 거라면 `admin/index.html` 파일을 크롬으로 바로 열어도 됩니다.

## 5. 처음 설정

1. 관리자 페이지 오른쪽 위 ‘설정’에서 ‘새로 만들기’를 눌러 채널 이름을 만들고, 학년별 반 수를 입력한 뒤 ‘저장’합니다.
2. 이 채널 이름을 메모해 둡니다. 모든 칠판과 관리자 기기에 똑같이 넣어야 합니다.
3. 관리자 페이지는 기기마다 따로 저장되므로, 다른 선생님 휴대폰에서도 처음 한 번은 채널 이름을 넣어야 합니다.

## 6. 칠판에 설치하기 (교실마다 한 번)

1. `app-debug.apk`를 USB에 담아 칠판에 꽂고, 파일 관리자에서 눌러 설치합니다. ‘출처를 알 수 없는 앱’ 허용을 물으면 허용합니다.
2. ‘교실 공지 알림’ 앱을 엽니다.
3. **반 이름**에 `1-3` 처럼 ‘학년-반’ 형식으로 넣습니다. 교무실 같은 곳은 관리자 페이지 ‘그 밖의 장소’에 적은 이름과 똑같이 씁니다.
4. **채널 이름**을 넣고 ‘저장하고 대기 시작’을 누릅니다. 상태가 ‘연결됨’으로 바뀌면 성공입니다.
5. ‘① 다른 앱 위에 표시 권한 허용하기’를 눌러 이 앱을 허용합니다. **이것을 하지 않으면 팝업이 뜨지 않습니다.**
6. ‘② 배터리 최적화에서 제외하기’를 누르고 허용합니다. 오래 켜 두어도 앱이 꺼지지 않게 합니다.
7. ‘테스트 팝업 띄워 보기’로 화면을 확인합니다.
8. 학생이 설정을 바꾸지 못하게 **설정 잠금 PIN**을 넣고 다시 저장합니다.

칠판을 껐다 켜면 앱이 자동으로 다시 대기합니다.

### 칠판에 ‘다른 앱 위에 표시’ 설정 화면이 없을 때

일부 칠판은 이 설정 화면을 업체가 숨겨 두었습니다. 이때는 PC에 칠판을 연결해 아래 명령으로 허용할 수 있습니다. 어렵다면 납품 업체에 이 문장을 그대로 전달해 부탁하면 됩니다.

```
adb shell appops set kr.chungmu.notice SYSTEM_ALERT_WINDOW allow
```

## 7. 공지 보내기

### 관리자 페이지 (PC, 휴대폰)

1. ‘받는 곳’에서 전체, 학년 전체, 특정 반을 고릅니다. 아무것도 고르지 않으면 전체 교실입니다.
2. 제목과 내용을 쓰거나 ‘자주 쓰는 문구’를 누릅니다.
3. 일반과 긴급(경고음)을 고르고, 표시 시간을 정합니다.
4. ‘공지 보내기’를 누릅니다.
5. 잘못 보냈다면 ‘떠 있는 공지 모두 닫기’를 누릅니다.

### ntfy 앱으로 보내기 (휴대폰, 선택)

관리자 페이지 대신 ntfy 공식 앱(안드로이드, 아이폰 모두 무료)으로도 보낼 수 있습니다.

1. ntfy 앱에서 ‘+’를 눌러 같은 채널 이름을 구독합니다.
2. 채널에 들어가 메시지를 보내면 전체 교실에 뜹니다.
3. 특정 반에만 보내려면 내용 맨 앞에 `[1-3]`, `[1학년]`, `[2-1, 2-4]` 처럼 적습니다.
4. 우선순위를 ‘높음’ 이상으로 하면 긴급 공지(경고음)로 뜹니다.

## 8. 알아 둘 점

- 칠판이 꺼져 있거나 인터넷이 끊겨 있던 동안의 공지는, 다시 연결된 뒤 10분이 넘은 것이면 띄우지 않습니다. 지난 공지가 뒤늦게 뜨는 것을 막기 위해서입니다.
- ntfy.sh는 무료 공개 서비스라 하루 전송 횟수에 넉넉한 제한이 있습니다. 학교 공지 용도로는 충분합니다.
- 채널 이름이 학생에게 알려졌다면, 관리자 페이지와 모든 칠판의 채널 이름을 새것으로 바꾸면 됩니다.
- 나중에 학교 PC에 ntfy 서버를 직접 설치해 운영하면, 칠판 앱과 관리자 페이지의 ‘서버 주소’만 바꿔서 그대로 쓸 수 있습니다.

## 9. 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 상태가 ‘연결 끊김’ | 칠판 와이파이 연결, 칠판 브라우저로 ntfy.sh 접속, 채널 이름 오타 |
| 연결됨인데 팝업이 안 뜸 | ① 권한 허용 여부, 반 이름이 관리자 페이지와 같은 형식인지(`1-3`) |
| 한참 뒤 앱이 멈춤 | ② 배터리 최적화 제외, 칠판의 ‘절전 모드’나 ‘앱 자동 종료’ 기능 끄기 |
| 소리가 안 남 | 칠판 미디어 음량 |
| 관리자 페이지에서 ‘보내지 못했습니다’ | 설정의 채널 이름, 휴대폰이나 PC의 인터넷 연결 |
